# 디자인 컨셉북 적용 플러그인

디자인 컨셉북 v1.0의 화면 가이드를 [Figma 와이어프레임](https://www.figma.com/design/9ExlElBFJhsqSCUQaT6lLP)의 01 · 02 · 06~09 · C-2 화면 그룹에 적용한 Figma 개발용 플러그인입니다. 2026-10-19에 한 번 실행해 오류 없이 적용을 마쳤습니다.

- **다시 실행해도 됩니다.** 이미 적용된 화면은 건너뜁니다.
- **네트워크 접근이 없습니다.** `manifest.json`의 `networkAccess`가 `none`입니다.
- 00 · 03 · 04 · 05 화면 그룹과 토큰 · 컴포넌트는 Figma MCP로 먼저 적용했고, 이 플러그인은 남은 화면만 처리합니다.

## 실행 방법

1. Figma 데스크톱 앱에서 와이어프레임 파일을 엽니다.
2. 메뉴 › 플러그인 › 개발 › 매니페스트에서 플러그인 가져오기 → 이 폴더의 `manifest.json`을 고릅니다.
3. 플러그인 › 개발 › **냠냠취미 컨셉북 적용**을 실행합니다. 결과 창에 화면별 처리 결과가 나옵니다.
